# Pull request review checklist

- [ ] Every changed line serves the purpose stated in the PR title and description.
- [ ] Link the related issue when one exists. Use `Closes #N` in the PR description when merging into the default branch should close it.
- [ ] List the checks you ran and their results. For example, verify that the new README link opens the checklist.
- [ ] Commit messages follow this repository's conventions (`feat:`, `fix:`, `docs:`, `refactor:`, or `chore:`).
